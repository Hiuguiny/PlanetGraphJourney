# 🚀 Viagem Espacial – Planet Graph Journey

Jogo simples feito em **HTML, CSS e JavaScript** para praticar o conceito de **grafos** e o **algoritmo de Dijkstra**.

## 📖 Sobre o projeto

O jogador controla uma nave e precisa viajar de um planeta inicial até um planeta destino.

- Os **planetas** são os vértices do grafo.
- As **rotas** entre eles são as arestas, cada uma com um custo de combustível.
- O jogador só pode se mover para planetas **vizinhos**.

O grafo foi representado com uma **lista de adjacência**. Ao chegar no destino, o jogo mostra o combustível gasto e compara com o **menor caminho possível**, calculado pelo algoritmo de Dijkstra.

## 🎮 Como jogar

1. Veja qual é o planeta atual e o destino.
2. Clique em um planeta vizinho para viajar.
3. Tente chegar ao destino gastando o mínimo de combustível.
4. Clique em **Reiniciar** para jogar de novo.

## ▶️ Como executar

1. Baixe ou clone o repositório:
   ```bash
   git clone https://github.com/Hiuguiny/PlanetGraphJourney.git
   ```
2. Abra o arquivo `index.html` no navegador.

Não precisa instalar nada.
